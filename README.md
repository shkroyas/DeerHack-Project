# BankSentinel

BankSentinel is a Five-Agent AI Intrusion Detection System designed for Real-Time Threat Correlation in Nepalese Banking Networks.

## Overview

This project implements a multi-agent system solving four core banking security challenges:
- **Challenge C1**: Zero-Day Attacks (Behavior Agent - BiLSTM)
- **Challenge C2**: High-Volume False Positives (Flow Agent - Context-aware Isolation Forest)
- **Challenge C3**: Alert Fatigue (Correlation Agent - Bayesian Fusion & Suppression)
- **Challenge C4**: Encrypted TLS 1.3 Traffic (Packet Agent - JA3/JA3S + Beacon IAT Analysis)

## Excluded Directories

Please note that the following directories are intentionally ignored by git:
- **`data/`**: Contains raw packet captures and large CSV datasets (such as CICIDS-2018 and CTU-13) used for training. These files are too large to be hosted on GitHub and should be downloaded locally or run via Google Colab.
- **`models/`**: Contains the compiled machine learning models (e.g., `.pkl`, `.pt` files). These trained artifacts can be quite large and are generated by running the training scripts or notebooks (typically via Google Colab) against the datasets.

To run the system locally, you must first train the models on Colab (or locally) and place the generated artifacts into the `models/` directory.

## Usage
- Train the models and download the artifacts into `models/`.
- Run the inference scripts (e.g., `correlation_inference_example.py`) to test the agent correlation pipeline.
